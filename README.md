# KrispyClient

Lightweight HUD and QoL mod for Minecraft Java Edition, Fabric 1.20.1. No combat or movement hacks — safe for survival servers.

## Features

- CPS counter (left + right click)
- Coordinates display
- Live FPS counter
- Armor durability per slot
- Toggle HUD with Right Shift

## Requirements

- Minecraft 1.20.1
- Fabric Loader 0.15.11+
- Fabric API
- Java 17

## Install

1. Install Fabric Loader for 1.20.1 in your launcher.
2. Download the latest `.jar` from [Releases](https://github.com/Coolguyhehe2515/KrispyClient/releases/latest).
3. Put it in your `mods` folder.
4. Launch with the Fabric profile.

## Build from source

```
gradle build
```

Output jar is in `build/libs/`. Use the non-`-sources` jar.

Builds also run automatically via GitHub Actions on push to `main`.
