A lightweight HUD and QoL mod. CPS, coords, FPS, armor durability — no combat or movement hacks, safe for survival servers.

↓ Download latest .jar
v0.1.0 fabric loader 0.15.11+ java 17

Features

  • hud CPS counter, left & right click
  • hud Coordinates + live FPS
  • hud Armor durability, per slot
  • key Right Shift toggles the HUD on/off

Install

  1. Install Fabric Loader 0.15.11+ for Minecraft 1.20.1 in your launcher (Zalith Launcher supports this directly).
  2. Download the .jar above.
  3. Move it into your mods folder.
  4. Launch with the Fabric profile — Right Shift toggles the HUD in-game.
